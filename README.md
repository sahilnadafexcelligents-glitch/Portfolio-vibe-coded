# Sahil.dev Portfolio

Dark React portfolio for a Java developer. It includes a home page, about page,
skills page, projects page, experience page, contact page, and login demo page.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

```text
src/
  App.jsx
  main.jsx
  styles.css
```

## Customize

Update the portfolio content in `src/App.jsx`, then replace placeholder links
and contact details with your real GitHub, LinkedIn, resume, and email.
